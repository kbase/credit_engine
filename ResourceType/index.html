    Enum: ResourceType

    The type of resource being represented.

    __

    Values combine the DataCite resourceTypeGeneral vocabulary (v4.7) with the resource types used by Commonmeta, Crossref, and OSTI. Where a resource type exists in DataCite, the DataCite term is used.

    __
